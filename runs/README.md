# Model Runs Directory

This directory contains YOLOv8 object detection model training outputs, including:
- Trained weights (best.pt, last.pt)
- Training metrics and curves
- Validation results and confusion matrices

## Structure
- `detect/train/` - Initial training run results
- `detect/train3/` - Latest training run results
- `detect/predict/` - Prediction outputs

Model weights are stored in `*/weights/` subdirectories.
