## 🚀 How to Use

### Start Backend
```bash
cd d:\AI-Powered_Civil_Infrastructure
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python finalwebapp_api.py
```

### Start Frontend
```bash
cd frontend
npm install  # if needed
npm start
```

### Access
- **UI**: http://localhost:3000
- **API**: http://localhost:5002
